## 🏛 Про проєкт
Високотехнологічний та естетично довершений веб-портал для найстарішої студентської наукової організації України (заснована 26 жовтня 1881 року).
Поєднує академічну велич понад 140-річної спадщини видатного педіатра, професора **Олександра Андрійовича Киселя**, та передовий цифровий дизайн медичного авангарду.

### ⚡ Ключові особливості дизайну та функціоналу:
- **Типографіка:** Фірмовий геометричний заголовочний шрифт **Druk Wide Cyr** (повна підтримка кирилиці та латинки для заголовків та бейджів) у поєднанні з *Plus Jakarta Sans* та *JetBrains Mono*.
- **Інтерактивний фон:** Органічна синаптично-нейронна сітка на HTML5 Canvas, що плавно реагує на курсор користувача.
- **Складні наслоєння:** Багаторівневий Glassmorphism (скляні панелі з блюром 24px, 1px градієнтні обводки, об'ємні 3D-перспективні картки).
- **Каталог 65+ студентських наукових гуртків (СНГ):**
  - Миттєвий живий пошук за назвою, кафедрою чи ключовими словами.
  - Фільтрація за фаховими напрямками (Хірургічний, Терапевтичний, Педіатрія, Стоматологія, Фармація, Фундаментальна медицина, Психічне здоров'я, Тактична медицина).
- **Інтерактивна хронологія (1881 — 2026):** Від створення «Клінічного товариства студентів-медиків» до сучасної цифрової епохи.
- **Флагманські події та конференції:** Секція щорічної міжнародної конференції **AYMSConf** та лекторію **Kysil Talks**.
- **Науковий журнал:** Співзасновництво фахового видання МОН України (категорія Б) — «Український науково-медичний молодіжний журнал» (USMYJ).
- **Керівництво та зв'язок:** Контакти Голови Ради СНТ (Роман Сирватка), прямі посилання на Telegram-канали гуртків (`@GurtkyNMU`) та СНТ (`@sntnmu`), Instagram, Facebook, YouTube.
- **Швидка форма вступу в СНТ:** Інтерактивне модальне вікно з валідацією та синхронізацією з офіційною Google-формою.
- **Аудіо-синтезатор UI:** Тактильні мікрозвуки інтерфейсу на чистому Web Audio API (можливість вимкнення в один клік).

## 📂 Структура проєкту
```text
KYSIL/
├── index.html                  # Головна сторінка порталу
├── .nojekyll                   # Забезпечує пряму роздачу GitHub Pages
├── README.md                   # Документація проєкту
└── assets/
    ├── css/
    │   ├── fonts.css           # Підключення Druk Wide Cyr (@font-face)
    │   └── style.css           # Комплексні брендові стилі, анімації, сітки

    │   ├── DrukWideCyr-Bold.woff2
    │   ├── DrukWideCyr-Bold.woff
    │   └── DrukWideCyr-bold.ttf
    ├── js/
    │   ├── circles-data.js     # База даних гуртків (СНГ)
    │   └── main.js             # Canvas, пошук, модальне вікно, аудіо
    └── images/
        ├── snt-avatar.jpg      # Офіційна емблема СНТ імені Киселя

        ├── snt-banner.jpg      # Портрет/банер спадщини Киселя
        ├── nmu-logo-white.svg  # Офіційний білий герб НМУ
        ├── nmu-logo-blue.svg   # Офіційний синій герб НМУ
        └── nmu-favicon.png     # Фавіконка НМУ
```
